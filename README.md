# PP2: Интерактивная карта с точками

Веб-приложение на FastAPI, которое отображает интерактивную карту (Folium) с точками, сохраненными в базе данных (SQLite).

## Стек
- **Python**
- **FastAPI** — бэкенд
- **SQLAlchemy** — ORM
- **SQLite** — база данных
- **Folium** — генерация карт
- **Jinja2** — шаблонизатор для HTML

## Функционал
- Просмотр карты с маркерами из БД (`GET /`).
- Добавление новой точки (`POST /add_point`).
- Валидация координат (широта от -90 до 90, долгота от -180 до 180).
- Логирование запросов и ошибок.
